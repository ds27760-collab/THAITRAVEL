# ThaiStay — HTML, CSS & JavaScript

เว็บไซต์ตัวอย่างระบบค้นหาและจองที่พักในประเทศไทย ดีไซน์ Luxury Minimal (ดำ / ครีม / ทอง)

## เทคโนโลยี
- HTML5
- CSS3
- Vanilla JavaScript
- ไม่มีฐานข้อมูล / ไม่มี Backend / ไม่มี Framework

## โครงสร้างไฟล์
```text
thaistay-html/
├── index.html
├── search.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── vercel.json
└── README.md
```

## ทดลองบนเครื่อง
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิด `index.html` ด้วย Live Server หรือเปิดไฟล์ในเบราว์เซอร์โดยตรง
4. หน้าแรก: `index.html`
5. หน้าค้นหาที่พัก: `search.html`

## Deploy บน Vercel
1. สร้าง GitHub repository ใหม่
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้เข้า repository
3. เข้า https://vercel.com และ Sign up / Log in ด้วย GitHub
4. เลือก Add New → Project
5. Import repository ที่เพิ่งสร้าง
6. Framework Preset เลือก Other (หรือปล่อยให้ตรวจจับเป็น Static)
7. Build Command: เว้นว่าง
8. Output Directory: `.` (จุด) หรือปล่อยค่าเริ่มต้นตามที่ Vercel แนะนำสำหรับ Static project
9. กด Deploy
10. เมื่อเสร็จแล้วเปิด URL ที่ Vercel แสดงให้

ไฟล์ `vercel.json` กำหนดให้ `/` เปิด `index.html` และ `/search` เปิด `search.html`

## ขอบเขตการทำงานและข้อจำกัด
- ค้นหา/กรองจังหวัด ราคา คะแนน และสิ่งอำนวยความสะดวกได้จากข้อมูลตัวอย่างใน JavaScript
- แบบฟอร์มจองเป็นเพียงการสาธิต และเก็บรายการไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น
- ไม่มีการตรวจสอบห้องว่างจริง ไม่มีการชำระเงินจริง ไม่มีการส่งอีเมล และไม่มีการจองกับโรงแรมจริง
- รูปภาพและ Google Fonts ใช้แหล่งภายนอก จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงผลครบถ้วน
- หากเปิดใช้งานจริง ต้องเชื่อมต่อระบบหลังบ้านและผู้ให้บริการชำระเงินที่ปลอดภัย

## ทดสอบก่อนเผยแพร่
- เปิดหน้าแรกและหน้าค้นหา
- ทดสอบค้นหาจังหวัดจากหน้าแรก
- ทดสอบตัวกรองราคา คะแนน และสิ่งอำนวยความสะดวก
- ทดสอบแบบฟอร์มจองด้วยข้อมูลสมมติ
- ทดสอบ Responsive บนมือถือ
